# Component and module migration checklist

Source inventory includes every Vue component, including icons and unrouted components: [components.json](components.json). Dependencies come from executable imports and dynamic `.vue` imports; an import alone does not establish that a conditional view was displayed. The scope includes 327 module components in 45 module groups.

“Source migrated” means a component uses the shared content contracts or its existing semantic styles were retained after inspection. It is not populated visual or live functional acceptance. The routed-view captures are offline with empty lookup responses. Individual records, financial roles and live mutations remain pending.

Native module enum selects remain native where their string contracts differ from the object-valued shared select. No competing select implementation or unused UI library was introduced.

PrimeVue 4.5.5 and installed Aura token shapes were inspected directly. The preset explicitly covers shared field semantics, button geometry, checkbox/radio selected contrast, toggle selected states, date selection and overlays. InputNumber, autocomplete, direct DataTable, Drawer and ConfirmDialog have no direct module instantiations in the audited templates; no replacement business feature was added for them.
