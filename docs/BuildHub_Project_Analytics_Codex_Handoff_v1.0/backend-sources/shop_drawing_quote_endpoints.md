# Shop Drawing Quote APIs

This document describes the frontend contract for the **Shop Drawing Quote** Store and Fetch endpoints.

## 1. Store Shop Drawing Quote

### Endpoint

```text
store_shop_drawing_quote
```

### Request

```json
{
  "quote_id": 140,
  "title": "MEP Shop Drawing",
  "date": "2026-10-12",
  "version_number": "V1",
  "file": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD/...",
  "project_timeline_stage_ids": [7, 17]
}
```

### Request Fields

| Field | Type | Required | Description |
|---|---|---:|---|
| `quote_id` | integer | Yes | Quote ID |
| `title` | string | Yes | Shop Drawing title |
| `date` | date / null | No | Drawing date in `YYYY-MM-DD` format |
| `version_number` | string | Yes | Version / revision number, e.g. `V1`, `Rev-02` |
| `file` | base64 string / null | Depends on backend validation | File encoded as Base64 |
| `project_timeline_stage_ids` | integer[] | Yes | List of main `project_timeline_stages.id` values |

### File Notes

- `file` is sent as **Base64**.
- The backend handles file decoding and storage.
- The frontend should send the complete Base64 string in the format supported by the backend.
- Shop Drawing uploads can support file types handled by the backend attachment cycle, including AutoCAD-related files where supported.

### Stage Rules

`project_timeline_stage_ids` contains IDs from `project_timeline_stages.id`.

Only **main timeline stages** are allowed:

```text
parent_id = null
```

The selected stages must belong to the same Quote, Project, and Organization.

The frontend does **not** send:

```text
project_id
organization_id
organization_employee_id
custom_number
```

These values are resolved/generated by the backend.

### Custom Number

`custom_number` is generated automatically by the backend based on:

```text
same quote_id
+
same exact set of project_timeline_stage_ids
```

Stage order does not matter, so `[7, 17]` and `[17, 7]` are treated as the same stage set.

Example sequence for the same Quote and same exact Stage Set:

```text
First record  -> custom_number = 1
Second record -> custom_number = 2
Third record  -> custom_number = 3
```

A different Stage Set starts again from `custom_number = 1`.

## 2. Fetch Shop Drawing Quotes

### Endpoint

```text
fetch_shop_drawing_quotes
```

### Request

```json
{
  "quote_id": 140
}
```

### Response Example

```json
{
  "status": true,
  "message": "Shop drawing quotes fetched successfully.",
  "data": [
    {
      "id": 1,
      "employee": {
        "id": 1,
        "name": "Techlab Employee",
        "type": 1
      },
      "quote_id": 140,
      "project_id": 86,
      "title": "MEP Shop Drawing",
      "date": "2026-10-12",
      "version_number": "V1",
      "file": "http://localhost:8000/storage/shop_drawing_quotes/e0m7uU88RA_1791803773.jpg",
      "custom_number": 1,
      "stages": [
        {
          "id": 7,
          "stage": {
            "id": 129,
            "title": "منعم"
          },
          "sub_stage": null,
          "created_at": "2026-10-07 14:08:48"
        },
        {
          "id": 17,
          "stage": {
            "id": 129,
            "title": "منعم"
          },
          "sub_stage": null,
          "created_at": "2026-10-11 11:33:28"
        }
      ],
      "created_at": "2026-10-12 11:16:13"
    }
  ]
}
```

### Response Fields

| Field | Description |
|---|---|
| `id` | Shop Drawing Quote ID |
| `employee` | Employee who created the record |
| `quote_id` | Related Quote ID |
| `project_id` | Related Project ID |
| `title` | Shop Drawing title |
| `date` | Drawing date |
| `version_number` | Drawing version / revision |
| `file` | Stored file URL |
| `custom_number` | Auto-generated sequence number for the same exact stage set inside the same Quote |
| `stages` | Main Project Timeline Stages linked to the drawing |
| `created_at` | Creation datetime |

### Stage Response Notes

Inside `stages`, each `id` is `project_timeline_stages.id`.

Example:

```json
{
  "id": 7,
  "stage": {
    "id": 129,
    "title": "منعم"
  },
  "sub_stage": null
}
```

means:

```text
7   = project_timeline_stages.id
129 = stages.id
```

Because Shop Drawing Quotes only accept main Timeline Stages, `sub_stage` should normally be `null`.

## Frontend Quick Reference

### Store

```text
POST store_shop_drawing_quote
```

```json
{
  "quote_id": 140,
  "title": "MEP Shop Drawing",
  "date": "2026-10-12",
  "version_number": "V1",
  "file": "BASE64_FILE_CONTENT",
  "project_timeline_stage_ids": [7, 17]
}
```

### Fetch

```text
POST fetch_shop_drawing_quotes
```

```json
{
  "quote_id": 140
}
```

### Important Frontend Rules

- Send `file` as Base64.
- Send only main `project_timeline_stage_ids`.
- Do not send `project_id`.
- Do not send `organization_id`.
- Do not send `organization_employee_id`.
- Do not send `custom_number`.
- `custom_number` is generated automatically by the backend.
