## Scope and notation

This catalog covers 63 non-icon reusable Vue components: 53 under `src/shared`, five base dialog components, three Vue starter components, and two application shells. Module-specific feature components are cataloged with their modules in [Modules documentation](MODULES_DOCUMENTATION.md). Individual SVG/icon components are intentionally excluded.

In the tables, `—` means the component declares no such public contract. Examples are deliberately minimal and assume normal imports. Slots in braces are scoped-slot values.

## Usage guidance

- Prefer `DataStatusBuilder` around controller `DataState` values rather than duplicating loading/error branches.
- Use `UpdatedCustomInputSelect` where an existing controller supplies remote options; use static options for fixed enums.
- Use `LangTitleInput` or `MultiLangInput` for backend translation arrays/records and provide English and Arabic labels through i18n.
- Use `AppTable`, `Pagination`, `DropList`, and the base `DeleteDialog` to match existing CRUD pages.
- Do not rely on `PermissionBuilder` for access control. The authenticated user model has no permission collection, and the component currently exposes no functional permission gate; backend authorization is the enforceable boundary.
- Add a companion test for any modified shared `.vue` file to satisfy the repository's staged-file coverage gate.
