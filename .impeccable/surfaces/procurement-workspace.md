# Procurement

Mode: Operate. Refine the existing Quote workspace without replacing its shell, controls or API contracts.

## Direction contract

THESIS: Make purchasing decisions easier to scan with a confident charcoal header, quiet warm paper surfaces and precise copper emphasis. The user selected warm ivory, charcoal and copper, matching BuildHub.

OWN-WORLD: Existing quote tokens, DIN typography, PrimeVue dialogs, shared attachment components and established BuildHub controls. No new palette, fonts or raster assets.

STORY: Find a request, compare its saved supplier offers and store one order from Supplier Prices. View the authoritative order from Purchase Requests. Preserve pending-only eligibility, read-only confirmed offers, draft recovery and price-record identifiers.

FIRST VIEWPORT: Quote navigation, introduction and creation action, three-step guide, searchable requests and status filters with truthful result counts.

FORM: Saved-offer selection, a clear selected summary, date and notes with shared field help, existing attachment input and deliberate Store/Cancel actions. Details retain read-only metadata and the shared attachment preview.

FINISH: Two bounded mocked browser rounds covered desktop, mobile and Arabic RTL. One correction batch addressed mobile overflow, duplicated guide numbering and control contrast; a final selector-specificity correction was checked against the shell source. Ship verdict with that correction source-validated rather than recaptured. Validation and remaining baseline limitations are in Procurement DESIGN_REVIEW.md. No shipping raster requires provenance.
